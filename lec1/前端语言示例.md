## 1. 一个最小 HTML 页面

保存为 `index.html`。可以直接使用浏览器打开。

``` html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>我的第一个网页</title>
</head>
<body>
    <h1>欢迎来到海客松</h1>
    <p>这是我的第一个网页。</p>
    <button>点击我</button>
</body>
</html>
```

### 关键结构

-   `<!DOCTYPE html>`：声明文档使用 HTML5。
-   `<html>`：HTML 文档的根元素。
-   `<head>`：放置标题、字符集等文档信息。
-   `<body>`：放置页面主体内容。
-   `<h1>`：一级标题。
-   `<p>`：段落。
-   `<button>`：按钮。

## 2. CSS 样式示例

## 3. JavaScript：点击按钮修改页面

下面的 HTML 和 JavaScript 共同实现点击按钮后修改标题文字。

### HTML

``` html
<h1 id="message">等待点击</h1>
<button id="myButton">点我</button>
```

### JavaScript

``` javascript
const button = document.querySelector("#myButton");

button.addEventListener("click", function() {
    document.querySelector("#message").innerText = "报名成功！";
});
```

### 关键概念

-   `document.querySelector()`：根据 CSS 选择器查找页面元素。
-   `addEventListener()`：监听事件。
-   `click`：鼠标点击事件。
-   `innerText`：读取或修改元素的文本内容。
-   `const`：声明一个不能重新赋值的变量绑定。

### 4.3 `script.js`

``` javascript
const usernameInput = document.querySelector("#username");
const registerButton = document.querySelector("#registerButton");
const message = document.querySelector("#message");

registerButton.addEventListener("click", function() {
    const username = usernameInput.value.trim();

    if (username === "") {
        message.innerText = "请先输入姓名。";
        message.style.color = "#ff9b9b";
        return;
    }

    message.innerText = `你好，${username}！前端演示报名成功。`;
    message.style.color = "#65d5a0";
});
```

### 4.4 如何运行

1.  创建 `campus-event` 文件夹。
2.  将三个代码块分别保存为对应文件。
3.  确保三个文件位于同一个文件夹中。
4.  双击 `index.html`，使用浏览器打开。
5.  输入姓名，点击"立即报名"。

> 注意：这个练习只是前端演示。报名结果只在当前页面中显示，并没有真正提交到服务器，也没有写入数据库。

## 7. JavaScript：通过 Fetch 请求 API

``` javascript
fetch("/api/events")
    .then(response => response.json())
    .then(data => {
        console.log(data);
    })
    .catch(error => {
        console.error(error);
    });
```

这段代码的基本过程：

1.  向 `/api/events` 发送请求。
2.  等待服务器响应。
3.  将响应正文解析为 JSON。
4.  在控制台查看数据。
5.  如果请求过程中发生错误，进入 `catch`。

注意：`/api/events`
是示例接口地址。只有当对应后端服务已经运行，并且提供了这个接口时，请求才会成功。直接通过
`file://` 打开的本地 HTML 页面，不一定适合演示
Fetch；建议使用本地开发服务器，并使用完整的 API 地址。

## 8. HTTP API 示例

前后端可以约定类似下面的接口：

  方法   地址                  用途
  ------ --------------------- --------------
  GET    `/api/events`         获取活动列表
  GET    `/api/events/123`     获取活动详情
  POST   `/api/register`       提交报名
  GET    `/api/user/profile`   获取用户资料

一个简化的 JSON 响应示例：

``` json
{
    "success": true,
    "message": "报名成功"
}
```

HTTP 方法的常见含义：

-   `GET`：获取数据。
-   `POST`：创建数据或提交操作。
-   `PUT`：更新资源。
-   `DELETE`：删除资源。

## 9. 数据库表结构示例

关系型数据库可以将数据组织在不同的表中。

### users 用户表

  字段       含义
  ---------- --------------
  id         用户唯一标识
  username   用户名
  email      邮箱

### events 活动表

  字段         含义
  ------------ --------------
  id           活动唯一标识
  event_name   活动名称

### registrations 报名表

  字段       含义
  ---------- ------------------
  id         报名记录唯一标识
  user_id    对应用户的 ID
  event_id   对应活动的 ID

`registrations.user_id` 可以关联 `users.id`，`registrations.event_id`
可以关联 `events.id`。

## 10. SQL：CRUD 基本操作

以下示例以 `users` 表为例。

### 查询（Read）

``` sql
SELECT * FROM users;
```

### 新增（Create）

``` sql
INSERT INTO users (username, email)
VALUES ('张三', 'zhang@example.com');
```

### 修改（Update）

``` sql
UPDATE users
SET username = '张三丰'
WHERE id = 1;
```

### 删除（Delete）

``` sql
DELETE FROM users
WHERE id = 1;
```

> 注意：真实操作时，尤其是 `UPDATE` 和 `DELETE`，要谨慎检查 `WHERE`
> 条件。缺少条件可能导致修改或删除大量记录。

## 11. 运行与安全提醒

### 11.1 为什么 HTML 可以直接打开？

浏览器已经内置 HTML 解析、CSS 处理和 JavaScript 引擎。双击 HTML
文件并不是跳过了解析与执行，而是浏览器替开发者提供了运行环境。

### 11.2 JavaScript 是否需要编译器或解释器？

JavaScript 并非不需要编译和解释。现代浏览器的 JavaScript
引擎通常结合解释执行与
JIT（即时编译）优化。开发者通常不需要自己安装，是因为浏览器已经内置了这些能力。

### 11.3 前端能不能直接连接核心数据库？

常规 Web
应用不应把数据库账号、密码或高权限凭据放进前端代码。浏览器中的代码可以被用户查看和修改。通常由后端验证身份、权限和业务规则，再通过数据库驱动或
ORM 操作数据库。

### 11.4 本地 HTML 文件的限制

`file://`
本地文件模式受到浏览器安全策略限制。一些模块导入、Fetch、跨源资源访问等功能可能无法按预期工作。遇到这些情况时，使用本地开发服务器通常更合适。
